О сервисе

Этот сайт выполняет прямые запросы к базам RDAP/WHOIS через официальные региональные интернет-регистраторы (ARIN, RIPE NCC, APNIC, LACNIC, AFRINIC). Никакие сторонние коммерческие API не используются — только открытые публичные протоколы, благодаря чему данные максимально точные и актуальные. Дополнительно сервис автоматически формирует Google Dorks и поисковые запросы для OSINT-анализа на основе полученной информации. Это позволяет быстро находить связанные публичные упоминания, домены, поддомены и другие открытые источники информации. Все сформированные поисковые запросы предназначены для поиска только общедоступной информации.

Точность

Данные берутся напрямую из RDAP-протокола регионального регистратора.

Скорость

Асинхронный FastAPI-бэкенд обрабатывает запрос за секунды.

Приватность

Мы не храним историю ваших запросов на сервере.

Частые вопросы

Что такое WHOIS/RDAP?

Это открытые протоколы, позволяющие узнать, кому принадлежит IP-адрес или домен: провайдера, страну, диапазон сети и контакты администратора.

Можно ли пробить приватный IP (192.168.x.x)?

Нет, такие адреса используются только внутри локальных сетей и не зарегистрированы ни в одном публичном реестре.

Хранится ли история запросов?

Нет, сервис не сохраняет введённые IP-адреса и результаты запросов.
